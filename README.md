
# World's Easiest Game [jam version]

A brief demo/jam version/original version of a game about not wanting to win the World's Easiest Game by waiting thirty seconds, and instead pushing the giant yellow button in the middle to play microgames and add time to the timer.

## Demo

Play the game [here](https://dorcdev.itch.io/worlds-easiest-game).
